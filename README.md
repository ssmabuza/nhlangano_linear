# Introduction

The fully parallel multiphysics solver on unstructured meshes based on Panzer, Kokkos and other Trilinos packages.

For architecture, equation sets, closure models, and implementation status, see [docs/CODE_DOCUMENTATION.md](docs/CODE_DOCUMENTATION.md).

# Building Dependencies

To compile Trilinos, a build script is included. It will help the user to compile trilinos and include Panzer and STK Interface.
